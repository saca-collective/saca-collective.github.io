# SACA - System Architects for Climate Action

## Introduction

SACA is an open collective of system architects, applying their practice to address the climate and ecological crises. We do this by collectively researching problems, designing solutions and engaging with organisations involved with climate and ecology.

## System Architects

System Architects are usually identified as Cloud, Solution or Enterprise architects within the corperate environment. SACA opens up this environment so that architects can operate "in the wild" as an open collective for a [Public Good](https://en.wikipedia.org/wiki/Public_good).
